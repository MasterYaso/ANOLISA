# 更新记录

[English](CHANGELOG.md)

记录 Omarchy 发行集成中用户可见的变化。以下版本为待 review 的发布准备，尚未发布。

## [0.1.3] - 2026-11-20

### 新增

- 提供 Omarchy 顶栏下拉窗口，可打开 cosh 和 AW 管理的 Qoder 会话，查看安全扫描详情与 Tokenless 处理记录。
- 默认使用英文，可切换中文；提供账户与模型配置、组件帮助、状态和诊断。
- 提供预编译的 Linux x86_64 安装包和离线校验安装。Qoder 为可选组件，单独从其官方来源下载。

### 修复

- 从首页直接打开帮助时，窗口保持显示。
- 在启动 cosh 的子进程中，避免 mise 的缺失命令处理替换 cosh 的自然语言处理。

### 兼容性

- 仅支持 Omarchy Linux x86_64。账户配置和统计按用户保存，安全扫描服务从 root 所有的安装文件运行。
- 下拉窗口不保留已关闭的终端会话。扫描次数不等于拦截次数；Tokenless 估算不等于账单节省。
